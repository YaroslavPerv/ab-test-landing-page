# A/B-тестирование: анализ конверсии лендинга

**Стек:** Python, pandas, NumPy, Matplotlib, SciPy, statsmodels, Jupyter Notebook

## О проекте

Исследование результатов A/B-тестирования двух версий страницы образовательного сервиса.

**Бизнес-задача:** определить, приводит ли новый дизайн страницы к увеличению конверсии пользователей, и на основании статистического анализа оценить целесообразность его внедрения.

В рамках проекта проведены очистка данных, исследовательский анализ, проверка статистической гипотезы и интерпретация результатов эксперимента.

## Ключевые результаты

| Показатель | Значение |
|---|---:|
| Наблюдений после очистки | 288 635 |
| Конверсия старой страницы | 12,04% |
| Конверсия новой страницы | 11,87% |
| Изменение конверсии | −0,17 п. п. |
| Z-статистика | −1,4036 |
| P-value | 0,1604 |

**Главный вывод:** статистически значимого улучшения конверсии при использовании новой страницы не обнаружено (α = 0,05).

По результатам проведённого эксперимента нет достаточных оснований рекомендовать внедрение нового дизайна с целью повышения конверсии.

## Этапы исследования

### 1. Исследование и подготовка данных

- Изучена структура датасета и распределение пользователей по экспериментальным группам.
- Проверено наличие повторяющихся идентификаторов пользователей.
- Выявлены несоответствия между назначенной группой и фактически показанной страницей.
- Подготовлена очищенная выборка для статистического анализа.

**Результат:** сформирован датасет из 288 635 наблюдений для основного анализа.

### 2. Разведочный анализ (EDA)

- Исследованы размеры контрольной и экспериментальной групп.
- Рассчитаны конверсии для обеих версий страницы.
- Проанализировано распределение трафика и изменение показателей во времени.
- Построены визуализации для сравнения групп.

### 3. Проверка статистической гипотезы

Сформулированы гипотезы:

- **H_0:** конверсии старой и новой страниц равны.
- **H_1:** конверсии страниц различаются.

Для сравнения долей использован двусторонний Z-тест.

Получено значение **p-value = 0,1604**, превышающее уровень значимости 0,05.

Следовательно, нулевая гипотеза не отвергается: статистически значимого различия в конверсиях не обнаружено.

### 4. Бутстрап-анализ

Дополнительно применён бутстрап для изучения неопределённости оценки конверсии.


## Итоговые выводы

1. После очистки данных конверсия контрольной группы составила 12,04%, экспериментальной — 11,87%.
2. Наблюдаемое изменение конверсии составляет −0,17 процентного пункта.
3. Статистический тест не выявил значимого различия на уровне α = 0,05.
4. Полученные результаты не дают достаточных оснований для внедрения новой страницы ради увеличения конверсии.
5. Для более определённого решения могут потребоваться дополнительные данные и дальнейшие эксперименты.
